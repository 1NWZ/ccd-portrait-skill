# ccd-portrait-skill

面向 Codex 的中文人像写真 Skill。它把用户照片作为唯一身份来源，把目标参考图拆成可执行的构图、姿态、光影、色彩、相机表面、造型层级与环境叙事。

## 核心能力

- 身份保真：保留脸型、五官、虹膜、自然肤色、年龄、体型、发际线与真实皮肤纹理。
- 参考优先：有目标图时不随机换场景，不把街拍目标改成白墙商业肖像。
- CCD 质感：近距离 24–35mm、有限动态范围、局部白色剪切、深黑压暗、冷调自动白平衡、细颗粒、暗部彩噪和克制直闪。
- 冷感超模：无笑、疏离、有压迫感；结构化先锋服装、设计眼镜与受控多层配饰。
- 参考偏差审核：生成后同时检查身份与风格，关键锚点偏离时定向修复一次。

## 两种模式

### 参考优先模式

用户提供明确目标图时，先锁定参考规格，再生成。目标图可以决定站姿或坐姿、前景透视、近脸持伞、配饰层级和背景运动；手不得触脸或扶眼镜，服装默认禁止单肩。

### 自由变化模式

没有目标图时，在白色建筑、花材墙面、公路车道和海边庄园之间变化，并轮换全身、七分身、腰上与胸像；开阔场景优先全身或七分身，避免不同用户得到同一套画面。

## 伞下城市 CCD 主配方

当目标接近 `assets/ref-06-umbrella-city.png` 时，Skill 会固定：

- 黑伞上方大轮廓、城市道路、远景建筑与运动模糊车辆；
- 早期数码 CCD、24–35mm 近距离轻广角、正午硬日光 + 克制机顶直闪；
- 黑色窄框深色眼镜 + 冷白网纱 + 珍珠/闪片/羽毛三级造型；
- 钴蓝、蓝黑、冷白、淡粉和少量香槟金；
- 明显局部高光剪切、深黑图形重量、轻微 JPEG 锐化、彩噪、色散和动态模糊；
- 目标支持时使用低墙/路缘坐姿、前景屈膝和近脸持伞，但不触脸或眼镜。

## 使用

```text
使用 $ccd-portrait-skill 将我的人像制作成身份保真的冷感超模 CCD 写真；有目标图时优先还原其构图、姿态、色彩、曝光、造型层级和环境叙事。
```

## 文件

- `SKILL.md`：任务路由、身份规则、参考优先模式、U1 主配方、中文 Prompt 和质检。
- `references/style-bible.md`：稳定审美与禁止项。
- `references/camera-light-realism.md`：CCD、胶片、光影、曝光和色彩规则。
- `references/scene-system.md`：参考路由与自由变化场景。
- `references/eyewear-and-styling.md`：眼镜、服装、发型、姿态和配饰层级。
- `assets/`：仅作风格证据，不作身份参考；其中的文字、Logo、UI 与人物身份不得进入结果。
