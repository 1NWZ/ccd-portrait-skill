# 场景与变化系统

本文件用于选场景并避免所有用户得到同一张图。S0–S6 都共享固定主光：**高位正午硬顶日光**。场景只改变机位、辅助光、服装、眼镜、发型、姿势和环境叙事。

## 选择方式

用户明确指定场景时直接服从。未指定时，从可见输入计算一个稳定但可变化的编号：

- 构图：横图 `0`，竖图/方图 `1`；
- 脸方向：画面左 `0`，正面 `1`，画面右 `2`；
- 发型体量：短/贴 `0`，中等 `1`，长/蓬松 `2`；
- 原衣服明度：浅 `0`，中 `1`，深 `2`；
- 系列序号从 `0` 开始。

`scene = (构图 + 脸方向 + 发型体量 + 衣服明度 + 系列序号) mod 7`，对应 S0–S6。

辅助光按 `(脸方向 + 衣服明度 + 系列序号) mod 3` 选择：无辅助、克制正面直闪、逆光发丝/窄耀斑。辅助光不得改变正午硬顶日光这个主光前提。

## S0 — 白色庄园建筑坐姿

- 参考：`../assets/ref-01-architectural-hat.png`
- 环境：一面粗糙白/浅灰墙、一个窄开口或一扇百叶窗、蓝天留白；删除多余建筑构件。
- 景别：竖版三分之二身或接近全身，平视到轻微低机位，人物偏置在建筑竖线之间。
- 姿势：坐靠或侧靠，一手承重，一腿沿石阶拉出长对角线，头低下或转开。
- 造型：黑色 oversize 长外套/西装 + 单肩内搭 + 米白/奶油缎面长裙或阔腿裤；一个焦点配饰。
- 发型：紧凑低髻、玻璃感长发或金棕顺滑发束；硬光下有独立亮发丝。
- 眼镜：E1 微型玫瑰无框或 E3 珠宝无框；眼镜为主角时不要再加大帽。
- 过曝：白墙和浅色裙裤出现明显过曝核心与局部柔溢，脸部中间调完整。

## S1 — 欧式喷泉或拱廊行进

- 参考：`../assets/ref-02-archway-walk.png`
- 环境：一个喷泉石面/水光锚点，或一面浅色拱廊；地面简洁，花材最多一条稀疏路径。
- 景别：略低机位竖版全身，建筑/水线提供对角线。
- 姿势：迈步、肩胯反向、手插西装或扶腰，长布料向后运动；脸保持冷静清晰。
- 造型：雕塑感黑色西装 + 简洁设计内搭 + 米白长裙/阔腿裤，或单件不对称礼服。
- 发型：贴头低马尾、半扎金棕长发或受控风吹；发尾可轻微动态模糊。
- 眼镜：E4 机械微型银框或无眼镜；如果水面反光复杂，减少其他金属配饰。
- 辅助：逆光发丝最合适；水面和浅色石材高光可溢出，禁止全场白雾。

## S2 — 花材边缘倚靠/半躺

- 参考：`../assets/ref-03-floral-recline.png`
- 环境：一面风化灰墙或棚体 + 一团不规则花材，最多四种低饱和颜色；删除工具、杂物和无关植物。
- 景别：浅高角度三分之二身，膝腿进入强光斑。
- 姿势：肩背有支撑地半躺，一臂压入花材，另一手自然承重；身体形成折线而非平躺人像。
- 造型：宽肩黑西装 + 低领内搭 + 光洁浅色长裙/宽裤；花材已是焦点，不再堆重工首饰。
- 发型：湿发后梳、光泽 bob/lob、雕塑面部发束或铜金发丝。
- 眼镜：E3 珠宝无框或 E5 工业线框；镜片不应被花材和发丝穿透。
- 过曝：浅裙与花材可有强高光核心，脸可处半阴影但五官仍清楚。

## S3 — 公路硬光抓拍

- 参考：`../assets/ref-04-roadside-flash.png`
- 环境：沥青边缘 + 一片高草或暗墙；最多一个车辆轮廓，无路牌、车牌和交通杂物。
- 景别：横版中景或宽竖版，前景人物占主导，带轻微偷拍感。
- 姿势：身体斜向镜头、坐路缘或向前跨步；肩胯反向，一手碰眼镜或西装边缘。
- 造型：黑色 cutout/oversize 西装 + 设计内搭 + 光洁阔腿裤或长礼服；重工链条与眼镜二选一为主。
- 发型：金棕/蜂蜜金凌乱控制发束、偏分长发或紧凑短发；独立边缘发丝被太阳点亮。
- 眼镜：E2 白色雕塑椭圆、E5 工业线框或 E6 黑色包覆镜。
- 辅助：克制直闪可压住顶光眼窝；背景暗约 0.5–1 档，人物脸仍自然。
- 排除：没有用户明确要求且人物显然成年时，不加烟、酒或第二人物。

## S4 — 别墅庭院/车道坐姿特写

- 参考：`../assets/ref-05-wicker-chair.png`
- 环境：一面别墅/车道平面 + 一辆车的局部或一棵树，二者默认只选一个；保留大块沥青/墙面留白。
- 景别：略广角近景或三分之二身，低机位，膝腿/椅子构成前景三角。
- 姿势：一膝靠近镜头、一肩下沉、头偏轴、下巴略收；一只手真实承重，另一手可触碰眼镜。
- 造型：oversize 黑西装 + 简洁抹胸/低领内搭 + 珍珠白/淡粉光洁阔腿裤；成人可露肩颈或腰部之一。
- 发型：锐利中分/侧分长直发、贴头低马尾、半扎金棕发或湿感形状。
- 眼镜：从 E1、E2、E4、E6 中按脸型与车身/墙面颜色选择，不固定为黑框。
- 辅助：轻微正面直闪；手、浅色裤和镜片边缘可有明显 clipping 与柔溢。

## S5 — 巴黎街头/城市喷泉近景

- 参考：`../assets/ref-06-umbrella-city.png`
- 环境：巴黎感灰墙、石阶或喷泉平面 + 一根路灯/小型建筑片段/水面；不要出现可读店招和地标堆叠。
- 景别：低机位近景、坐姿特写或轻微旋转的面部近景；可用伞形成上方黑色图形，但不是必需。
- 姿势：一膝向镜头、身体后靠或前倾，手握伞柄/扶眼镜/支撑台面；避免正中对称。
- 造型：暗黑 oversize 西装/长外套 + 法式简洁露肩内搭 + 光洁礼服裤/长裙；只保留一个重工焦点。
- 发型：贴头低髻、半扎香槟金发、湿感 bob 或控制面部碎发。
- 眼镜：E1 微玫瑰、E3 珠宝无框、E5 工业线框或 E6 黑色包覆镜。
- 辅助：无辅助或窄发丝逆光；脸清晰，驶过车辆或水面可有轻微动态模糊。

## S6 — 海边庄园草坪/公路运动

- 参考：`../assets/ref-07-coastal-motion.png`
- 环境：干净草坪、一道公路、一面浅色别墅和细海平线；最多一个暗色车身，删除额外车辆、栏杆和杂乱绿化。
- 景别：膝/腰高度的竖版全身低机位，深蓝天空或海平面提供大块留白。
- 姿势：迈步、抬腿或长裙摆随动作移动，躯干逆向倾斜；脸和上身保持清晰，裤脚/裙摆轻微动感模糊。
- 造型：干净黑色 pinstripe/雕塑西装 + 小众设计内搭 + 米白阔腿裤或偏置长裙；白色结构包或金属鞋只选一个。
- 发型：风吹低马尾、金色/铂金控制长发或两束雕塑面部发丝。
- 眼镜：E1、E4 或 E6；天空与镜片反光必须符合角度。
- 过曝：浅色裤/裙、白墙、包或鞋形成明显高光核心，黑色西装保持深。

## 系列规则

- 人物身份、自然肤色、年龄、发际线、发量、发根与身体比例全程一致。
- 正午硬顶日光始终为主光；辅助光不连续重复。
- 场景至少轮换 4 个家族后再重复；近景、中景、全身、浅高角度交替。
- 用户没有锁定原发色时，金色系发色约占一半到三分之二，其余保留自然发色；连续图片不重复同一发型 + 发色。
- 眼镜约占三分之一到二分之一；连续图片不重复同一 E 家族。
- 同一配饰最多出现在一半图片中；每张独立成片，不生成拼图。

## 定向修复 Prompt

只加入对应失败项，同时重复身份锁定：

- **换脸/漂白**：“恢复图 1 的脸型、五官、自然肤色、年龄、发际线、发量和体型；风格图不得影响身份，不得白化皮肤、改蓝眼或强制极瘦。”
- **表情不够超模**：“去掉友好、甜美和礼貌感；下巴略收、头偏轴、嘴唇轻闭或微张，改为无笑、疏离、厌世且有压迫感的清冷超模表情。”
- **穿搭太普通**：“建立 oversize/雕塑大轮廓 + 设计内搭 + 阔腿裤/礼服体量 + 单件重工焦点，融合暗黑先锋、法式轻奢与少量 Y2K，保持比例夸张但层级清楚。”
- **衣服显廉价**：“删除细碎皱纹、密集抽褶、微荷叶边、廉价压皱、碎百褶和过多滚边；恢复大块干净裁片、高级面料与宽大受控重力褶。”
- **硬光不足**：“把主光恢复为高位正午硬顶日光，形成清晰鼻影、颌影与服装硬阴影；禁止阴天均匀光和影棚柔光。”
- **过曝不足**：“让浅色受光区域约 10–25% 成为明确过曝核心，周围增加局部低半径柔光溢出；保留过渡材质、人脸中间调和深黑阴影。”
- **胶片感不足**：“加入 Portra 400 类肤色响应、明显但细腻的颗粒与轻微褪色；保持写实清晰，禁止橙青调、重划痕和全局奶雾。”
- **发丝不亮**：“用硬日光或逆光分离暖金/中性白的独立边缘发丝，少量飞发接近过曝；发根保持真实，不要整圈合成光环。”
- **姿势太普通**：“建立至少两条强对角线或一个三角，肩胯反向、手部有支点、重量明确，并用低机位或近镜膝盖强化比例。”
- **背景太乱**：“只保留一个主平面、一个语境锚点和 20–40% 留白；删除额外车辆、交叉栏杆、杂乱植物、路牌、人群、垃圾和多余窗户。”
- **没有眼镜/眼镜错**：“从 E1–E6 选择一款适配脸型与场景的眼镜，准确贴合鼻梁与双侧镜腿，恢复真实镜片厚度、透视和反光；删除 Logo、伪文字与穿模发丝。”
- **抓拍感不足**：“脸与眼镜保持清晰，在发尾、裙摆、抬手边缘或背景加入轻微方向性动态模糊；不要模糊五官。”
- **污染元素**：“删除品牌、文字、车牌、水印、播放按钮、页码、浏览器边框、拼图和重复人物，只输出一张完整照片。”
