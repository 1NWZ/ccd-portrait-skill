# 场景与变化系统

本文件只在没有明确目标图时提供变化；有目标图时，先使用 SKILL.md 的参考优先模式，并选择最接近的场景配方。严禁随机选择一个“干净场景”覆盖目标图的构图和叙事。

## 路由规则

1. 目标出现黑伞、城市道路、深色窄框眼镜、网纱、车辆或近距离前景透视：固定 U1。
2. 目标出现白色建筑、宽檐帽、长礼服、花束和强日照：选择 S1。
3. 目标出现花材包围、墙边倚靠或半躺：选择 S2，并按目标姿态；没有目标图时不主动半躺。
4. 目标出现公路、高草、车道、强直闪和行进感：选择 S3。
5. 目标出现海边庄园、草坪、白墙和深蓝天空：选择 S4。
6. 目标只给气氛而未给场景：选择与用户照片构图兼容且与上一张不同的 S1–S4。
7. “白墙 + 窗框 + 靠墙胸像”不再是默认方案；只有目标图明确如此才使用 S5。

## U1 — 伞下城市 CCD（主目标配方）

- 场景：黑伞主轮廓 + 城市道路 + 远景建筑轮廓 + 1–2 辆运动模糊车辆；不复制特定地标、品牌、文字或车牌。
- 相机：C0 早期数码 CCD，24–35mm 近距离轻广角，有限动态范围，克制机顶直闪。
- 构图：竖版头部至大腿；黑伞占上方 25–40%，人物偏轴；靠近镜头的膝腿占下方 20–35%，与肩线、伞柄形成强三角。
- 姿态：低墙或路缘坐姿，躯干略后撑，头部正对或轻偏镜头；一手握伞柄靠近脸侧但不碰脸/眼镜，另一只手支撑身体或出画。
- 表情：眼睑放松、下巴略收、无笑、正视镜头，带厌世和压迫感。
- 面部系统：黑色窄框/猫眼深色镜片 + 冷白细网纱；镜片仍可读，网纱覆盖脸但不能替换五官。
- 服装：双肩稳定的黑色闪片/细亮点宽肩西装 + 对称低领或中央深 V 内搭 + 冰粉/淡粉结构裤；羽毛袖口、珍珠链作为次级材质。
- 发型：默认保留原发色并用硬侧逆光点亮独立发丝；用户确认变色后可用铂金/香槟金与真实深发根。
- 光色：正午硬日光照环境和发丝，直闪提伞下脸与珠宝；钴蓝、蓝黑、冷白、淡粉、少量香槟金。
- 曝光：发丝、网纱、珍珠、浅色裤装局部剪切；黑伞、黑西装与远景树影压深；禁止灰平 HDR 和米灰商业色。

## S1 — 白色建筑与拱廊

- 环境：白色风化建筑、一个拱洞或窗洞、深蓝天空；花束或烟雾只选一项。
- 相机：C0 或目标明确时 C1；24–35mm，轻微低机位。
- 构图：默认七分身或全身，建筑线条与肩线/腿部形成对角；目标是近景时继承目标。白墙不是空背景，而是强光与阴影的图形平面。
- 姿态：迈步、转身、站姿前倾；若目标明确坐在建筑边缘，可按目标使用坐姿。
- 造型：黑色雕塑宽肩外套 + 对称浅色内搭/礼服 + 宽檐帽或花束；焦点层级不超过三级。
- 光色：正午硬光，白墙明显局部剪切，阴影带钢蓝；浅黄/香槟礼服只作色彩点。

## S2 — 花材与风化墙面

- 环境：一面风化木/灰墙 + 成片但受控的白、淡黄、浅粉花材；背景仍保留暗块与空隙。
- 相机：C0 或 C1，35mm 近景。
- 构图：目标有倚靠/半躺时复刻其承重点；无目标时使用七分身或腰上斜构图，连续系列不得重复景别。
- 姿态：肩线倾斜、头部反向、手臂形成折线；禁止甜美花园照。
- 造型：黑色宽肩西装 + 对称内搭 + 结构化长裙/裤；花材是环境，不成为婚礼布景。
- 光色：硬光切过脸和花，浅色花瓣局部剪切，墙面和黑衣压深。

## S3 — 公路、车道与高草

- 环境：沥青、路缘、高草或一辆车局部；可以有 1–2 辆运动中的车或一个无脸模糊路人。
- 相机：C0 或 C3，24–35mm；允许背景方向性运动模糊。
- 构图：人物偏一侧，公路形成斜向负空间；默认全身或七分身，目标为近景时继承目标。
- 姿态：迈步回看、站姿前倾、靠车门但不坐，或目标支持时坐在低矮路缘。
- 造型：oversize 黑西装 + 对称紧凑内搭 + 结构裤；眼镜使用窄黑深色、白色雕塑或包覆式之一。
- 光色：正午硬日光、直闪或侧逆光按目标选择；深蓝天空、黑色车身、冷白与少量金属色。

## S4 — 海边庄园草坪

- 环境：草坪、一道公路、一面浅色别墅、细海平线和深蓝天空；车辆局部不超过两辆。
- 相机：C0、C1 或 C3，以参考图为准。
- 构图：默认全身或七分身，轻微低机位、人物偏轴；深蓝天空保留 20–35% 负空间，脚部完整，地面线与衣摆/裤腿形成前景运动。
- 姿态：迎风停步、迈步、转身或目标支持的夸张前景腿部动作；重心必须可解释。
- 造型：pinstripe/雕塑西装 + 对称内搭 + 建筑感结构裤/礼服 + 一个结构手袋或金属鞋。
- 光色：硬光、深蓝天空、白色建筑与黑色车身形成强对比；发丝和浅色织物可剪切。

## S5 — 目标明确的墙面近景

仅当目标图本身就是墙面近景时使用。不得在参考包含道路、伞、车辆、喷泉或庄园时选用。

- 环境：一面有质感的墙 + 单一窗/门洞；不得变成无信息奶油背景。
- 相机：优先 C0/C3 35mm；只有参考明确时使用 C4 85mm。
- 构图：必须有强阴影切割、偏轴裁切或近距离畸变，禁止平视居中商务肖像。
- 姿态：按目标复刻；无目标时站姿转身、肩线倾斜、手臂形成对角。

## 定向修复

- 误生成白墙商务肖像：切换到与目标对应的场景；恢复背景锚点、轻广角、强黑白关系和姿态承重点。
- 构图太普通：拉近到 24–35mm，增加前后景尺度差、斜线、局部裁切和明确承重点；禁止回退 85mm 居中胸像。
- U1 缺少目标元素：恢复黑伞、深色窄框眼镜、网纱、珍珠/羽毛、车辆运动和淡粉前景中的目标层级。
- 表情太友好：去掉微笑和睁大眼；眼睑放松、下巴略收、嘴唇轻闭/微张。
- 裤装像睡衣：改用高密华达呢/厚重哑光绉/挺括斜纹，加入建筑分割和 2–4 条主受力褶。
- 手扶眼镜或摸脸：保留近脸持伞/持道具的几何，但让手与镜框、嘴唇、鼻梁和脸保持清楚距离。
- 高光不足：只提高发丝、网纱、珍珠、浅色衣料和建筑受光核心，不整体提亮。
- 颜色太米灰：锁定钴蓝、蓝黑、冷白、冰粉和少量香槟金，压深黑位。
