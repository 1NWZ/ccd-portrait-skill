# 场景与变化系统

本文件用于避免每个人得到同一张图。S0–S6 都默认保留原发色、采用站姿（站立、迈步、转身或靠墙不落座），并服从“禁单肩、禁坐姿、禁扶镜摸脸”。每个场景给出默认景别——全身 FS、七分身 MS、腰上 MW 或胸像 CU；景别随系列轮换，开阔场景默认全身或七分身。

## 选择逻辑

1. 从用户照片读取脸方向、发长、服装明度与画面比例，但不沿用自拍背景。
2. 在 S0–S6 中选一个与上一张不同的场景，并采用该场景的默认景别；系列中胸像与腰上合计不超过一半，连续两张景别不同。
3. 从 C1–C5 只选一个成像配置（含其 EXIF 参数），从 L1–L5 只选一个主光模式；C5 与 L5 配对使用。
4. 从外轮廓、内搭、结构化下装、姿势、眼镜中各选一个；原发色保持不变。
5. 背景采用“一个主平面 + 一个锚点 + 15–35% 留白”，最多一个无脸模糊路人；全身与七分身中环境占画面约 35–50%。

参考图中的坐姿、半躺、单肩服装、扶镜和摸脸动作只作为反例，不得复制。

## S0 — 风化白墙与单扇窗

- 环境：一面有颗粒的白/灰泥墙 + 单扇窗或门洞；裂纹只留一两处。
- 成像/光：C1 Portra 400 + 35mm，f/2.8、1/500s、ISO 400；L2 侧逆光。白墙给暗侧脸极轻冷白反射。
- 构图：默认 MW 腰上；人物落在左或右五分之二线，另一侧保留墙面留白；裁掉一侧外套边缘。
- 姿势：站立靠墙但不落座，躯干转 30°，头部回转 10°，一肩略高；双手画外或一手插袋。
- 造型：宽肩黑西装 + 双肩对称深 V/方领内搭；结构化裤装只在画面底部露少量腰线。
- 发型：在原发色上做玻璃感分缝、贴头低马尾或受控飞发；边缘发丝被侧逆光分离。
- 高光：墙面、浅色领口和发丝局部剪切，脸不大面积过曝。

## S1 — 石阶与暗门洞

- 环境：宽石阶作为线性平面 + 一个暗门洞；人物始终站在台阶上，不得坐下。
- 成像/光：C4 85mm，f/1.8、1/320s、ISO 200；L4 建筑边缘遮挡硬光。暗门保持深黑。
- 构图：默认 MS 七分身（膝盖以上），偏轴；石阶斜线穿过背景并在脚下形成透视；门洞轻微遮挡人物轮廓约 5%。
- 姿势：站立转身，躯干转 20–35°，头部反向回看；一手在胸口以下整理袖口。
- 造型：雕塑短外套 + 对称高领/中央 cutout + 高密华达呢裤或建筑感长裙。
- 发型：原发色湿发后梳、紧凑低髻或雕塑面部发束。

## S2 — 欧式喷泉与石面

- 环境：一段喷泉石面 + 小面积水光；不堆雕像、栏杆和花坛。
- 成像/光：C1 Portra 400 + 35mm，f/2.8、1/500s、ISO 400；L1 正午硬顶。石材提供极轻冷白反射。
- 构图：默认 MS 七分身，人物在三分线，喷泉边缘形成一条强斜线，地面水光提供透视；可有一小片前景水光遮挡衣服边缘。
- 姿势：迎风停步，重心偏一侧，肩线与水面反向；双手画外或腰线以下握衣摆。
- 造型：修长黑外套 + 双肩对称简洁内搭；结构化下装不出现软缎睡衣感。
- 发型：保持原发色的贴头低马尾、半扎或受控风吹。
- 高光：水面、金属、浅色织物小面积明显溢出；面部保留眼窝和鼻底阴影。

## S3 — 公路边与高草

- 环境：沥青边缘 + 一片高草或暗墙；最多一个车辆局部，不出现车牌。
- 成像/光：C5 CCD 便携机直闪，38mm、f/3.5、1/125s、ISO 100；L5 正面直闪（日光下作为补闪，保留阳光投影）。暗部保留 CCD 彩色噪点与边缘紫边。
- 构图：默认 FS 全身，宽竖版或横版；人物偏一侧，公路与高草留出较大负空间并在脚下形成透视，环境占画面约 40–50%；裤脚随步伐轻微动态模糊。最多一个无脸模糊路人轮廓。
- 姿势：向前迈步后短暂停住，身体斜向镜头，腿部形成对角线；一手插袋，另一手自然摆动或出画。
- 造型：oversize 黑西装 + 双肩对称紧凑皮革内搭 + 涂层棉/厚重哑光绉裤。
- 发型：原发色受控风吹、偏分或紧凑短发；发尾轻微运动模糊。
- 排除：无明确成年与用户请求时不加烟酒。

## S4 — 别墅庭院或车道

- 环境：一面别墅/车道平面 + 一辆车局部或一棵树，二选一；不出现椅子。
- 成像/光：C3 iPhone 原相机感，28mm、f/1.8、1/120s 原生直出；L3 树影斑驳。绿植在暗侧下颌产生极轻蓝绿色反射。
- 构图：默认 MS 七分身，略广角、轻微低机位，人物落在五分之二线；腿部与车道地面线形成透视。
- 姿势：站立向镜头轻微前倾，躯干转约 25°，肩线一高一低；一手插袋或整理袖口。
- 造型：双肩稳定的 oversize 西装 + 对称方领/深 V/抹胸 + 挺括斜纹结构裤。
- 发型：保持原发色的锐利中分、低马尾、半扎或湿感形状。
- 高光：浅色领口、袖口和镜片边缘局部剪切；叶影不规则切过一侧额头或颧骨。

## S5 — 巴黎灰墙或城市喷泉

- 环境：巴黎感灰墙、石面或喷泉平面 + 一根路灯/模糊车辆/水面，三选一；不出现可读店招。
- 成像/光：C2 Kodak Gold 200 + 35mm，f/4、1/250s、ISO 200；L4 帽檐/黑伞/建筑遮挡硬光。
- 构图：默认 MS 七分身，偏轴；上方黑伞可形成图形，伞沿与身体形成斜线，但手须停在胸口以下；街面在脚下提供透视。
- 姿势：站立转身或沿墙行进，头部回看；另一手插袋或在画外。
- 造型：暗黑长外套 + 双肩对称高领/方领/深 V + 结构化裤装；重工焦点只选眼镜或伞。
- 发型：保留原发色的低髻、湿感 bob 或控制面部碎发。
- 背景：可允许一个无面孔的模糊路人穿过远景，不得抢焦点。

## S6 — 海边庄园草坪

- 环境：干净草坪、一道公路、一面浅色别墅和细海平线；最多一个暗色车身局部。
- 成像/光：C1 Portra 400 + 35mm，f/2.8、1/500s、ISO 400；L1 正午硬顶或 L2 侧逆光，二选一。
- 构图：默认 FS 全身，竖版、膝/腰高度低机位，人物位于三分线，头顶到脚部完整入画，深蓝天空/海平线提供 30–40% 留白，草坪与公路线条向远处收束。
- 姿势：迈步、转身或迎风停步，躯干逆向倾斜；一手握外套下摆，另一手出画。
- 造型：干净 pinstripe/雕塑西装 + 双肩对称设计内搭 + 高密羊毛结构裤或建筑感长裙；全身构图中下装结构完整展示。
- 发型：原发色风吹低马尾、控制长发或两束雕塑面部发丝。
- 高光：白墙、浅色衣领和独立发丝局部溢出，黑西装保持深。

## 系列规则

- 身份、自然肤色、虹膜、年龄、体型、发际线、发量、发根和原发色全程一致。
- 只有用户明确允许变色时，发色才进入变化池。
- 场景至少轮换 4 个家族后再重复；景别在全身、七分身、腰上、胸像间轮换，连续两张不同，胸像与腰上合计不超过一半。
- 成像配置和主光不得在连续两张中完全相同；单张不得混合多个配置；C5 与 L5 配对出现。
- 每张都必须站立、迈步、转身或靠墙不落座；全身与七分身中脚部完整、环境占 35–50%。
- 每张服装肩部保持左右对称；双手不得触碰眼镜和面部。
- 同一配饰最多出现在一半图片中；每张独立成片，不生成拼图。

## 定向修复 Prompt

- **换脸/漂白**：“恢复图 1 的脸型、五官、虹膜、自然肤色、年龄、体型和头发基础；风格图不得影响身份。”
- **擅自改发色**：“恢复用户源图原发色、发根与眉发关系；只保留真实侧逆光照亮的独立发丝，不染金、不做假光环。”
- **表情太友好**：“去掉甜美和礼貌感；下巴略收、头偏轴、嘴唇轻闭或微张，改为无笑、疏离且有压迫感的超模凝视。”
- **构图普通/景别太近**：“按场景默认景别重拍：开阔场景用全身或七分身，脚部完整、头顶留白、地面线条有透视、环境占 35–50%；人物落三分线或五分之二线，留 15–35% 负空间；躯干转 20–45°、头部反向 5–15°、肩线一高一低，腿部形成对角线。”
- **没有相机质感**：“写入成像配置的完整参数（焦段、光圈、快门、ISO）；让胶片颗粒或 CCD 暗部彩色噪点在缩略图中可辨，加入暗角、边缘色散/紫边和裤脚/裙摆/步伐的方向性动态模糊；使用 C5 时正面直闪把人物切出、背景压暗 1–2 档；不要输出零颗粒的干净数码渲染图。”
- **裤装像睡衣**：“删除薄软贴腿缎面、松紧腰、抽绳、随机碎褶和软塌垂坠；改用高密华达呢/厚重哑光绉/挺括斜纹，加入建筑分割、清晰压褶和 2–4 条主要受力褶。”
- **出现单肩**：“把领口、肩带和外套恢复为左右对称；两侧肩部同时覆盖或同时露出。”
- **出现坐姿**：“改为站姿、迈步、转身或靠墙不落座，景别按场景默认；删除椅子、落座台阶、蹲跪、半躺和膝盖前景。”
- **手扶眼镜/摸脸**：“眼镜自然佩戴；双手与镜框、镜片、嘴唇、下巴和面部完全分离，改为插袋、整理袖口、腰线以下握衣摆或出画。”
- **手部畸形**：“恢复每只可见手五指、正确指节和拇指连接；若仍不可靠，把该手自然裁出画面。”
- **光线太均匀**：“移除全脸补光；保留眼窝、鼻底和下颌分层，加入符合场景的树影/帽檐/建筑遮挡、侧逆光或 CCD 正面直闪。”
- **皮肤像塑料**：“去掉磨皮、通透发光和全脸高光；恢复哑光毛孔、局部色差和仅 T 区少量油脂高光。”
- **过曝不足**：“让浅色真实受光区约 10–25% 成为明确过曝核心，周围仅有小范围 halation；保留脸中间调和黑色。”
- **背景太乱**：“只留一个主平面、一个锚点和 15–35% 留白；最多保留一个无脸模糊路人，删除其余杂物。”
