# 风格母版

本文件规定“ccd大片写真”为什么一眼成立。它是可执行的中文视觉语法，不是英文关键词翻译。

## 一句话导演意图

一位保留本人身份与原发色的清冷超模，以结构化先锋时装站在略普通、轻微风化的庄园、街道、喷泉、公路或庭院中；非均匀自然硬光切过面部与服装，局部白色高光明显溢出，画面带真实相机和复古胶片的轻微瑕疵，像一帧未经美颜的杂志抓拍。

## 六个核心

### 1. 清冷超模脸是锚点

- 无笑、疏离、厌世、疲惫或有压迫感；下巴略收，头部偏轴，嘴唇轻闭或微张。
- 冷感来自眼神、非均匀硬光和骨相阴影，不来自换脸、漂白、改蓝眼、放大眼睛或重塑五官。
- 皮肤保持真实哑光、自然肤色、毛孔和局部色差；只在 T 区有少量油脂高光。

### 2. 原发色默认锁定

- 默认保留用户原发色、发际线、发量、长度和发根方向。
- 只在用户明确要求改变发色时，才选择适配本人的铂金、香槟金、蜂蜜金、金棕、bronde 或铜金。
- 发丝“发光”指侧逆光照亮一根根边缘发丝；黑发可呈中性白/冷银边光，棕发可呈同色系暖边光，不等于统一染金。
- 发型要秀场化但可实现：玻璃感分缝、贴头低马尾/髻、湿发后梳、半扎、受控风吹或雕塑面部发束。

### 3. 高级混搭靠结构

以“3+1”组织：

- 一个 oversize/雕塑外轮廓；
- 一个双肩对称的高领、圆领、方领、深 V、抹胸、中央 cutout 或紧凑皮革内搭；
- 一个结构化裤装、建筑感长裙或偏置礼服；
- 最多一个重工焦点：眼镜、链条、结构手袋、帽或伞。

服装两侧肩部必须同时覆盖或同时露出；禁止单肩、斜肩、不对称肩带、单侧滑落和只露一侧肩颈。

裤装优先高密羊毛华达呢、厚重哑光绉、挺括斜纹、涂层棉、结构皮革或有骨感的技术缎。采用清晰压褶、建筑分割和立体省道，只保留 2–4 条主要受力褶。禁止松紧腰、抽绳、薄软贴腿缎面、睡衣垂感、密集碎皱和软塌家居感。

### 4. 自然光必须不均匀

- 单张只选：正午硬顶、侧逆光、树影斑驳、建筑/帽檐/头纱遮挡硬光中的一种。
- 拒绝全脸均匀补光。至少保留眼窝、鼻底、下颌中的两层阴影。
- 环境反射只做极轻局部色：绿植为蓝绿色、白墙为冷白、明确傍晚才为暖橘。
- 阴影与亮面不能被柔光填成同一亮度。

### 5. 过曝与相机瑕疵必须有依据

- 白墙、米白织物、浅色帽檐、金属、镜片边缘和发丝的真实受光核心可明显剪切，并有小范围 halation。
- 浅色受光区约 8–18% 可成为局部过曝核心；人脸中间调和黑色服装保持完整。
- 单张只用一个成像配置：Portra 400 + 35mm、Kodak Gold 200 + 35mm、iPhone 原相机感或 85mm 人像镜头。
- 轻微颗粒、畸变、暗角、边缘色散、暗部噪点、边缘失焦和局部动态模糊用于增加可信度，不得糊脸或变成滤镜特效。

### 6. 高级构图来自不平衡中的控制

- 默认胸像或腰部以上，人物位于三分线或五分之二线，留出 15–35% 负空间。
- 躯干转 20–45°，头部反向 5–15°，肩膀一高一低，重心偏一侧。
- 肩线、翻领、手臂与背景线构成至少两条对角线或一个三角。
- 允许有意裁掉一个肘部、外套边缘或少量发梢；背景锚点可遮挡人物边缘约 5–10%。
- 禁止证件照式完美居中、正面对称直立、坐姿、蹲跪、半躺、膝盖前景和椅子构图。

## 受控真实感

- 衣服只允许一处内衬轻微外翻和少量顺人体受力的宽褶；禁止满身乱皱。
- 配饰可有极轻旧化：珍珠轻微包浆、五金细小划痕、镜片一处轻微擦拭痕迹、头纱一两处细勾丝、布帽一个受压形变。
- 道具可有可信生活痕迹：书角微黄、干草碎边、花器小水渍。
- 最多允许一个无可辨认面孔的模糊路人轮廓；其余背景保持干净。

## 手部与姿势

- 双手远离眼镜和面部。只用插袋、胸口以下整理袖口、腰线以下握衣摆/结构手袋、自然垂落或出画。
- 可见手每只五指，指节、关节、拇指连接、指甲和腕部结构正确；无法保证时裁出画面。
- 包可轻微歪斜、头纱可不对称垂落，但服装肩部始终左右对称。

## 禁止项

- 参考模特换脸、漂白肤色、改虹膜、强制极瘦、擅自染发；
- 甜美自拍、礼貌微笑、证件照居中、目录式对称站姿；
- 单肩、斜肩、单侧滑落、坐蹲跪躺、膝盖前景、扶镜、摸脸、托腮；
- 松紧腰抽绳裤、睡衣裤、薄软贴腿缎面、密集细碎褶和廉价堆饰；
- 全脸均匀补光、环形灯眼神光、全局柔焦、磨皮、塑料皮、CGI 光泽；
- 同一张图堆叠多种胶片、多种焦段或矛盾光源；
- 橙青电影调、重划痕、漏光边框、全局奶雾、大块无纹理死白；
- 杂乱车辆、人群、路牌、垃圾、品牌、文字、车牌、水印、网页 UI 和拼图。
