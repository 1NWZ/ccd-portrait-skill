# 风格母版

本文件规定这套写真“为什么一眼成立”。它不是英文词库的翻译，而是可执行的中文视觉语法。

## 一句话导演意图

一位清冷、疏离的超模穿着带 Y2K、暗黑先锋与法式轻奢张力的高级混搭，在正午硬日光下出现在略普通、轻微风化的庄园、街道、喷泉或公路；画面像被杂志摄影师突然截获的复古胶片时刻，白色高光有明显柔溢，黑色仍锋利。

## 六个不可拆散的核心

### 1. 清冷超模脸是统一锚点

- 表情必须在缩略图中成立：无笑、冷淡、厌世、疲惫、疏离或直接压迫。
- 下巴略收，头部偏轴数度，嘴唇轻闭或微张；可直视镜头、半垂眼或看向画外。
- 冷感来自无笑冰冷凝视、冷白清透的瓷感妆光和高反差阴影，不来自换脸、漂白、改蓝眼或重塑骨相。
- 保留用户的自然肤色、虹膜颜色、年龄与纹理；硬光和克制修容可让眉骨、鼻梁、颧骨与下颌更锐利，但不得改变几何。

### 2. 高级混搭靠比例，不靠堆装饰

以“3+1”组织造型：

- 一个 oversize 西装、长外套或雕塑感礼服大轮廓；
- 一个设计内搭：单肩、抹胸、不对称领口、简洁镂空、干净深领或紧凑皮革；
- 一个体量下装：阔腿裤、偏置长裙、缎面礼服或光洁长裤；
- 最多一个重工焦点：设计眼镜、金属项链、结构手袋、鞋、帽或伞。

风格比例建议：暗黑先锋负责外轮廓，法式轻奢负责材质与露肤克制，Y2K 负责眼镜、金属或局部比例。三种语言必须有主次，不得平均堆满。

优先面料：紧密羊毛、哑光绉、细皮革、厚实顺滑缎、真丝/粘胶、挺括府绸。允许宽大重力褶和身体接触褶；拒绝细碎皱纹、密集抽褶、微荷叶边、廉价压皱、碎百褶、过多拼接与装饰滚边。

### 3. 精致时装与生活环境发生冲突

适合的环境：海边庄园、巴黎街头、欧式喷泉、普通公路、别墅庭院、车道、草坪、略旧石阶、粗糙灰泥墙。环境不必豪华，它需要真实、略普通或轻微未完成，从而衬托造型的昂贵。

每张图只使用一个主平面与一个锚点，例如：

- 粗糙浅墙 + 单扇蓝灰百叶窗；
- 宽石阶 + 一个暗门洞；
- 喷泉石面 + 一段水光；
- 巴黎灰墙 + 一根路灯或一辆模糊车辆；
- 公路/沥青 + 一片高草或一个车身轮廓；
- 海边草坪 + 一面白色别墅与细海平线。

保留约 20–40% 留白，最多两至三类背景元素。删除多辆车、交叉栏杆、杂乱灌木、垃圾桶、招牌、人群、多扇窗和无关家具。可以保留一道裂纹、一块褪色墙面或少量杂草，让现场可信。

### 4. 正午硬顶日光是固定主光

- 太阳位置高，鼻下、下颌、眼窝与衣服结构产生明确硬阴影。
- 主光不随机改成阴天柔光、日落金光或影棚柔光。
- 可选择一种辅助：无辅助、克制正面直闪、逆光发丝/窄耀斑；辅助不得消除硬顶光逻辑。
- 背景可比人物暗约 0.5–1 档，黑色服装压深，浅色与金属高光跃出。

#### 白色高光柔溢

- 白墙、象牙缎、米白裤、香槟金、浅花材、金属和眼镜边缘的最亮核心必须跨过剪切点。
- 大面积浅色受光区约 10–25% 可以成为过曝核心；周围增加局部低半径柔光/halation，缩略图也可见。
- 核心之外保留褶线、墙面颗粒、花瓣与物体体积；不得把整件衣服变成无纹理死白。
- 人脸只允许极小高光或极窄轮廓接近溢出；眼睛、鼻唇、下颌和自然肤色必须读得清。
- 黑色服装与阴影保持深、硬、无奶雾，形成“硬光源 + 软高光外溢”。

### 5. 复古胶片是表面，不是滤镜特效

- 使用 Portra 400 类的肤色响应、轻微褪色和温和高光过渡，但整体黑色偏冷，主色为冷黑、米白、香槟金。
- 胶片颗粒明显但细腻，主要落在阴影与中间调；脸部细节仍清晰。
- 允许轻微闪光不均、局部耀斑、发丝/裙摆运动和紧凑相机的直接感。
- 禁止橙青调、厚重划痕、漏光边框、全局柔焦、奶油棚拍渐变、HDR 与塑料般过度锐化。

### 6. 镜头必须有抓拍杂志感

- 镜头感 28–50mm；近距离可有轻微广角透视，但脸不能变形。
- 主要构图：低角度仰拍全身/三分之二身、近景人像、坐姿特写、浅高角度俯拍。
- 人物占画面约 55–85%，环境仍可识别；近景可用浅景深，但不能把场景抹成纯色虚化。
- 脸、眼睛、鼻唇和眼镜结构锐利；发尾、裙摆、抬手边缘、驶过车辆或背景可有轻微方向性动态模糊。
- 姿势至少形成两条强对角线或一个三角：长腿沿石阶延伸、膝盖向镜头、肩胯反向、身体前倾或一手承重。

## 色彩与材质配比

建议而非硬公式：

- 40–55% 冷黑、蓝黑、炭灰服装或阴影；
- 20–35% 米白、象牙、香槟、珍珠、淡粉或淡薰衣草浅色；
- 15–30% 墙面、道路、草地、海天或喷泉等环境色；
- 10% 以下金属、花材、包或眼镜焦点。

皮肤保持自然，不因“冷感”变灰白。饱和度选择性降低，蓝天、草地或车身可作为单一环境色块。

## 发型与发丝

- 发际线、发量、长度和发根方向属于身份锁定；分缝、表面、运动与允许的发色属于造型变量。
- 用户没有锁定原发色时，优先选择适配本人的铂金、香槟金、蜂蜜金、金棕、bronde 或铜金；系列中保留部分自然发色，避免每个人、每张图都统一金发。
- 适合的秀场结构：玻璃感长直发、控制 S 波、半扎结构、贴头低马尾、紧凑低髻、湿发后梳、湿感短发、风吹面部发束。
- 正午硬光或逆光下，独立发丝出现暖金或中性白边缘光；少量飞发接近过曝。禁止整圈假光环、黄色假发、漂浮发束和发丝穿镜。

## 眼镜

眼镜是场景焦点，不是每张图的统一制服。从 E1–E6 中选择，系列中约三分之一到二分之一使用眼镜，连续图片不重复同一轮廓。镜片必须有真实厚度、透视、反光和遮挡关系，镜架贴合鼻梁与双侧镜腿。禁止品牌、文字、浮空鼻托、融合铰链、左右镜片比例不一。

## 必须拒绝的失败画面

- 参考模特换脸、白化皮肤、改蓝眼、强制极瘦或把所有人统一成铂金发；
- 甜美自拍、网红微笑、对称红毯站姿、普通坐姿或没有承重点的手；
- 柔光棚拍、环形灯眼神光、阴天均匀光或把直闪做成轻微滤镜；
- 浅色无过曝峰值，或反过来整张奶雾、整脸漂白、大片无纹理死白；
- 服装细碎皱纹、密集抽褶、微荷叶边、廉价压皱、过多拼接和饰边；
- 背景同时出现多辆车、多条栏杆、杂乱植物、路牌、垃圾、行人和大量窗户；
- 过度浅景深导致环境不可读，或动态模糊覆盖脸和眼镜；
- 橙青电影调、重划痕、复古边框、塑料皮肤、CGI 光泽；
- 品牌、车牌、文字、水印、播放按钮、页码、浏览器 UI、拼图、边框或重复人物。
